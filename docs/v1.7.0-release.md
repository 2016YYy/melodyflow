# 发布说明 v1.7.0

## 主题
补齐后台播放能力（此前 pubspec 已声明 audio_service / audio_session，但 lib 从未接线，功能缺失）

## 改动清单
- lib/services/audio_handler.dart：基于 audio_service 的 BaseAudioHandler，双向同步播放状态到通知栏 / 锁屏 / 耳机线控
- lib/services/audio_player_service.dart：新增 onSongChanged / onPlaybackChanged 回调
- lib/providers/music_provider.dart：装配音频处理器，双向转发（通知栏控制 <-> 播放引擎）
- lib/main.dart：启动时初始化 audio_service 与 audio_session
- ios/Runner/Info.plist：增加 UIBackgroundModes: audio
- android/.../AndroidManifest.xml：声明 mediaPlayback 前台服务类型
- android/.../res/drawable/ic_stat_music_note.xml：单色通知图标
- CHANGELOG.md / pubspec.yaml：版本号 1.7.0+8

## 发布步骤
本地（或 TRAE CN）执行 scripts/release-v1.7.0.ps1 推送并打 tag，云端自动构建。
